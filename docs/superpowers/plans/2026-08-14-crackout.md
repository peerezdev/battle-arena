# Crackout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un modo nuevo donde la casa pone una carta dentro de una cápsula y los jugadores pagan gimmighouls para dar golpes, con cada golpe verificable en el momento mediante una cadena de hashes.

**Architecture:** Al crear una losa se deriva una semilla de un secreto del entorno, se hashea 10.000 veces y se publica solo el extremo. Cada golpe consume un eslabón hacia atrás y lo revela en la respuesta del mismo POST que lo cobra, todo en una transacción de base. El navegador rehace la cadena entera por su cuenta contra el extremo publicado.

**Tech Stack:** FastAPI, SQLAlchemy sobre SQLite, pytest. React con react-router, vitest, Web Crypto en el verificador. Privy para firmar la entrega de la carta.

**Spec:** `docs/superpowers/specs/2026-08-14-crackout-design.md`

## Global Constraints

Estos valores y reglas se aplican a TODAS las tareas. Están copiados literalmente del spec.

- **`N = 10.000`** eslabones por cadena. Constante, la misma para todas las losas.
- **`D = max(2, floor(insured_value * 2 + 0.5))`.** Se usa `floor(x + 0.5)`, **nunca** `round()`: Python redondea a par (`round(40.5) == 40`) y JavaScript no (`Math.round(40.5) === 41`). El verificador del navegador tiene que dar exactamente lo mismo que el servidor.
- **El script de creación rechaza `D > 1.000`** (unos 500 $ de valor asegurado), para dejar 10x de margen de cadena.
- **La clave del HMAC es la cadena hexadecimal codificada en UTF-8**, no los bytes decodificados. Igual en Python (`link.encode()`) y en el navegador (`new TextEncoder().encode(link)`).
- **Cada hash de la cadena se aplica sobre la cadena hexadecimal**, no sobre bytes: `sha256(link_hex_string)`. Es lo mismo que hace `seed_hash` en `provably_fair.py`.
- **La semilla nunca se guarda en la base.** Se deriva siempre con `HMAC(CRACKOUT_SECRET, slab_id)`.
- **El eslabón viaja en la respuesta del mismo POST que cobra el punto.** No existe ningún endpoint que revele un eslabón sin haberlo cobrado.
- **Copy de cara al jugador: nada de guiones largos (—).** Ni en la interfaz, ni en los anuncios del chat, ni en los textos del verificador.
- **La frase que se publica es "no podemos cambiar el resultado".** Nunca "no podemos influir en el sorteo". Va visible en la página del verificador, no en un pie de página.
- Comentarios y docstrings nuevos en español, como el código reciente del proyecto.

```python
"""Cadena de hashes de Crackout: las primitivas puras del sorteo.

Al crear una losa se deriva una semilla y se hashea N veces. Se publica SOLO el extremo. Cada
golpe consume un eslabón hacia atrás y se revela al instante, así que el jugador comprueba su
golpe en el momento, gane o pierda. Saber el eslabón de hoy no dice nada del de mañana: haría
falta invertir un SHA-256.

Esto sustituye al commit-reveal de `provably_fair.py`, que no sirve aquí: revela la semilla al
final, y una losa puede no romperse nunca. Las derrotas se quedarían sin verificar para siempre.

Todo lo de este módulo es puro: mismas entradas, mismas salidas, sin base y sin red. El
verificador del navegador reimplementa exactamente estas funciones, y `shared/crackout-vector.json`
es lo que impide que se separen.
"""
from __future__ import annotations

import hashlib
import hmac
import math

#: Eslabones por cadena. El script de creación exige que D deje 10x de margen sobre esto.
N_POR_DEFECTO = 10_000


def derivar_semilla(secret: str, slab_id: str) -> str:
    """Una cadena por losa, derivada al vuelo y JAMÁS guardada.

    Quien lea `battlearena.db` no conoce ni un golpe futuro. La contrapartida está asumida y
    escrita en el spec: si se pierde `CRACKOUT_SECRET`, las losas vivas quedan irresolubles.
    """
    return hmac.new(secret.encode(), slab_id.encode(), hashlib.sha256).hexdigest()


def siguiente(link: str) -> str:
    """Un eslabón hacia el extremo. Se hashea la cadena HEXADECIMAL, no los bytes decodificados,
    igual que `seed_hash` en provably_fair.py. El navegador tiene que hacer lo mismo."""
    return hashlib.sha256(link.encode()).hexdigest()


def extremo_cadena(seed: str, n: int) -> str:
    """h[n]. Es lo único que se publica al crear la losa."""
    h = seed
    for _ in range(n):
        h = siguiente(h)
    return h


def eslabon_del_golpe(seed: str, n: int, hit_index: int) -> str:
    """h[n - k] para el golpe k. Se recalcula desde la semilla en vez de guardar la cadena:
    son n-k hashes, unos 5 ms, y así la base no contiene ningún golpe futuro."""
    if not 1 <= hit_index <= n:
        raise ValueError(f"golpe {hit_index} fuera de la cadena (1..{n})")
    h = seed
    for _ in range(n - hit_index):
        h = siguiente(h)
    return h


def encadena(link: str, anterior: str) -> bool:
    """La comprobación del jugador. `anterior` es el extremo publicado en el primer golpe."""
    return siguiente(link) == anterior


def denominador(insured_value: float) -> int:
    """D, tal que p = 1/D. Se compromete como ENTERO: "1 entre 40" se audita a ojo.

    `floor(x + 0.5)` y no `round()`: Python redondea a par (round(40.5) == 40) y JavaScript no
    (Math.round(40.5) === 41). El verificador del navegador tiene que dar lo mismo que el
    servidor, y una divergencia aquí acusaría de tramposos a golpes correctos.

    Consecuencia bonita de D = 2V: el valor esperado de un golpe es p × V = 0,50 $ SIEMPRE. Una
    losa cara no paga peor, solo dura más.
    """
    return max(2, int(math.floor(insured_value * 2 + 0.5)))


def tirar(link: str, client_seed: str) -> int:
    """El dado. La semilla la elige el jugador, y no puede molerla: no conoce el eslabón hasta
    después de que se le haya cobrado el golpe."""
    d = hmac.new(link.encode(), client_seed.encode(), hashlib.sha256).digest()
    return int.from_bytes(d[:8], "big")


def rompe(roll: int, denominador_losa: int) -> bool:
    return roll % denominador_losa == 0
```

```python
class CrackoutSlab(Base):
    """Una losa de Crackout: una carta de la casa y la cadena de hashes que decide quién se la lleva.

    El COMPROMISO (chain_head, chain_length, denominator, cost_points) es inmutable desde
    committed_at. No se toca nunca, ni para corregirlo: cambiarlo invalida en silencio todas las
    verificaciones pasadas. Una losa mal creada se abandona y se crea otra.

    El precio del golpe vive AQUÍ y no en la configuración a propósito. Así se puede estrenar una
    losa barata y encarecer las siguientes sin invalidar nada, porque cada losa se comprueba
    contra su propio compromiso.

    La semilla NO está en esta tabla. Se deriva de CRACKOUT_SECRET (ver crackout_chain.py), así
    que quien lea la base no conoce ni un golpe futuro.
    """
    __tablename__ = "crackout_slabs"
    id: Mapped[str] = mapped_column(String, primary_key=True)   # slug corto, va en la URL
    nft_address: Mapped[str] = mapped_column(String)
    # Foto CONGELADA de la carta al crear la losa. Si Collector Crypt cambiara el valor asegurado
    # mañana, el "1 entre D" publicado dejaría de cuadrar con lo que se ve en pantalla.
    name: Mapped[Optional[str]] = mapped_column(String, nullable=True)
    image_url: Mapped[Optional[str]] = mapped_column(String, nullable=True)
    insured_value: Mapped[float] = mapped_column(Float)
    # ── el compromiso, inmutable ──
    chain_head: Mapped[str] = mapped_column(String)
    chain_length: Mapped[int] = mapped_column(Integer)
    denominator: Mapped[int] = mapped_column(Integer)   # D, tal que p = 1/D
    cost_points: Mapped[int] = mapped_column(Integer)   # gimmighouls por golpe
    committed_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=_now)
    # ── estado ──
    status: Mapped[str] = mapped_column(String, default="live", index=True)  # live|broken|exhausted
    hits: Mapped[int] = mapped_column(Integer, default=0)
    broken_by: Mapped[Optional[str]] = mapped_column(String, nullable=True)
    broken_at: Mapped[Optional[datetime]] = mapped_column(DateTime(timezone=True), nullable=True)
    # Nula con status="broken" = la carta todavía no ha salido de la vitrina. Es un estado
    # reparable y visible, no una carta perdida: `scripts/crackout.py --entregar` lo reintenta.
    delivery_signature: Mapped[Optional[str]] = mapped_column(String, nullable=True)


class CrackoutHit(Base):
    """Un golpe. Es el REGISTRO PÚBLICO append-only: nunca se borra ni se reordena.

    Existe para que reordenar deje huella. La cadena demuestra que no cambiamos el resultado de un
    golpe; no demuestra que no elijamos a quién le toca cada eslabón, porque el servidor conoce
    los eslabones futuros. Este registro hace ese reordenamiento detectable a posteriori. Detectar
    no es impedir, y por eso lo que se promete en público es solo lo primero.
    """
    __tablename__ = "crackout_hits"
    # La UNIQUE es la defensa de concurrencia: dos golpes simultáneos que calculen el mismo índice
    # no pueden coexistir, y el que pierde se deshace entero, cobro incluido. Va como índice y no
    # como UniqueConstraint por lo mismo que uq_earning_battle_referred: aquí no hay framework de
    # migraciones, y un índice se puede crear sobre una tabla que ya existe (ver _ENSURE_INDEXES).
    __table_args__ = (Index("uq_crackout_hit_index", "slab_id", "hit_index", unique=True),)
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    slab_id: Mapped[str] = mapped_column(String, index=True)
    hit_index: Mapped[int] = mapped_column(Integer)   # 1..N, estrictamente secuencial
    wallet: Mapped[str] = mapped_column(String, index=True)
    client_seed: Mapped[str] = mapped_column(String)
    link: Mapped[str] = mapped_column(String)         # el eslabón revelado
    roll: Mapped[int] = mapped_column(Integer)
    broke: Mapped[bool] = mapped_column(Boolean, default=False)
    # Lo COBRADO, copiado de la losa: el histórico no puede depender de una fila que se edite.
```

```python
"""El golpe de Crackout.

La regla que sostiene el modo: cobrar el punto, consumir el eslabón y revelarlo ocurren en UNA
transacción y sin marcha atrás. El eslabón viaja en la respuesta del mismo POST que cobró. Si
existiera cualquier hueco entre ver el resultado y pagarlo, se molería hasta ganar sin pagar los
fallidos.
"""
from __future__ import annotations

from datetime import datetime, timezone

from sqlalchemy import update
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from ..models import CrackoutHit, CrackoutSlab, User
from .crackout_chain import derivar_semilla, eslabon_del_golpe, rompe, tirar


class CrackoutError(Exception):
    """Raíz de los fallos esperables del modo, para que la capa HTTP los mapee sin adivinar."""


class LosaNoJugable(CrackoutError):
    """No existe, ya está rota o agotó la cadena."""


class SaldoInsuficiente(CrackoutError):
    pass


class LosaOcupada(CrackoutError):
    """Demasiados golpes simultáneos: se perdió la carrera por el índice varias veces seguidas."""


def dar_golpe(session: Session, slab_id: str, wallet: str, client_seed: str, *,
              secret: str, intentos: int = 3) -> CrackoutHit:
    """Un golpe, atómico. Devuelve el golpe ya persistido, con su eslabón revelado.

    Si dos peticiones calculan el mismo `hit_index`, la UNIQUE de `crackout_hits` hace fallar a
    una y su transacción se deshace ENTERA, cobro incluido. Se reintenta recalculando el índice.
    """
    for _ in range(intentos):
        try:
            return _un_golpe(session, slab_id, wallet, client_seed, secret=secret)
        except IntegrityError:
            session.rollback()
        except CrackoutError:
            session.rollback()
            raise
    raise LosaOcupada("demasiados golpes a la vez, inténtalo otra vez")


def _un_golpe(session: Session, slab_id: str, wallet: str, client_seed: str, *,
              secret: str) -> CrackoutHit:
    losa = session.get(CrackoutSlab, slab_id)
    if losa is None or losa.status != "live" or losa.hits >= losa.chain_length:
        raise LosaNoJugable("esta losa no admite golpes")

    # El cobro es un UPDATE condicional y no un read-modify-write: la condición de saldo la evalúa
    # la base, así que dos golpes simultáneos no pueden dejar el saldo en negativo entre los dos.
    cobrado = session.execute(
        update(User)
        .where(User.wallet == wallet, User.gimmighouls >= losa.cost_points)
        .values(gimmighouls=User.gimmighouls - losa.cost_points)
    )
    if cobrado.rowcount == 0:
        raise SaldoInsuficiente("no tienes gimmighouls suficientes")

    k = losa.hits + 1
    seed = derivar_semilla(secret, losa.id)
    link = eslabon_del_golpe(seed, losa.chain_length, k)
    roll = tirar(link, client_seed)
    roto = rompe(roll, losa.denominator)

    hit = CrackoutHit(slab_id=losa.id, hit_index=k, wallet=wallet, client_seed=client_seed,
                      link=link, roll=roll, broke=roto, cost_points=losa.cost_points)
    session.add(hit)
    losa.hits = k
    if roto:
        losa.status = "broken"
        losa.broken_by = wallet
        losa.broken_at = datetime.now(timezone.utc)
    elif k >= losa.chain_length:
        # Se agotó sin romperse. Seguir exigiría recomprometer en público, y eso parece un truco
        # aunque no lo sea, así que la losa se cierra y se crea otra.
        losa.status = "exhausted"
    session.commit()
    return hit


def vista_losa(losa: CrackoutSlab) -> dict:
    """Lo que se publica de una losa: el compromiso entero y el estado. Nada más.

    El compromiso va COMPLETO a propósito. Que cualquiera pueda copiar chain_head, chain_length y
    denominator es lo que hace verificable el modo; esconderlos no protegería nada, porque la
    seguridad está en no poder invertir un SHA-256, no en que el extremo sea secreto.
    """
    return {
        "id": losa.id, "nft_address": losa.nft_address, "name": losa.name,
        "image_url": losa.image_url, "insured_value": losa.insured_value,
        "chain_head": losa.chain_head, "chain_length": losa.chain_length,
        "denominator": losa.denominator, "cost_points": losa.cost_points,
        "status": losa.status, "hits": losa.hits, "broken_by": losa.broken_by,
        "broken_at": losa.broken_at.isoformat() if losa.broken_at else None,
        "delivery_signature": losa.delivery_signature,
        "committed_at": losa.committed_at.isoformat() if losa.committed_at else None,
    }


def vista_golpe(hit: CrackoutHit) -> dict:
    """`roll` va como TEXTO: son 64 bits y JSON.parse los redondearía al leerlos como number,
    así que el navegador no podría rehacer la comprobación. Se compara como BigInt."""
    return {
        "hit_index": hit.hit_index, "wallet": hit.wallet, "client_seed": hit.client_seed,
        "link": hit.link, "roll": str(hit.roll), "broke": hit.broke,
        "cost_points": hit.cost_points,
        "ts": hit.created_at.isoformat() if hit.created_at else None,
    }
```

```python
        """El registro público. Sin autenticación a propósito: que cualquiera pueda recorrerlo
        entero es lo que hace que reordenar deje huella."""
        if s.get(CrackoutSlab, slab_id) is None:
            raise HTTPException(404, "slab not found")
        golpes = (s.query(CrackoutHit)
                  .filter(CrackoutHit.slab_id == slab_id, CrackoutHit.hit_index > after)
                  .order_by(CrackoutHit.hit_index.asc()).limit(min(limit, 500)).all())
        return {"hits": [vista_golpe(h) for h in golpes]}

    @app.post("/crackout/{slab_id}/hit")
    async def crackout_golpear(slab_id: str, body: CrackoutHitBody,
                               wallet: str = Depends(current_user), s: Session = Depends(db)):
        # Sin secreto no hay cadena que consumir. Apagado explícito, no un fallo silencioso.
        if not crackout_secret:
            raise HTTPException(503, "crackout not configured")
        get_or_create_user(s, wallet, elo_start)
        s.commit()
        try:
            hit = dar_golpe(s, slab_id, wallet, body.client_seed, secret=crackout_secret)
        except SaldoInsuficiente:
            raise HTTPException(402, "not enough gimmighouls")
        except LosaOcupada:
            raise HTTPException(503, "too many hits at once, try again")
        except LosaNoJugable:
            raise HTTPException(409, "slab is not playable")
        losa = s.get(CrackoutSlab, slab_id)
        usuario = s.get(User, wallet)
        # La entrega de la carta se dispara FUERA de la transacción del golpe, en Task 5.
        return {"hit": vista_golpe(hit), "slab": vista_losa(losa),
                "points_left": usuario.gimmighouls if usuario else 0}
```

```python
"""Sacar la carta de la vitrina y dársela a quien rompió la losa.

Dos reglas, las dos aprendidas a base de golpes en el settle de las batallas:

1. PAGA EL OPERADOR, no la vitrina. Crear la cuenta de destino del ganador cuesta 2.039.280
   lamports, y una wallet que solo custodia cartas no tiene por qué llevar SOL encima. Con
   `fee_payer=operador` más su co-firma, el saldo de la vitrina deja de importar: solo firma como
   dueña de la carta. Es el fallo que sigue abierto en el settle, donde paga el escrow y no le llega.

2. ENVIADA NO ES ENTREGADA. `submit_signed_tx` devuelve firma en cuanto el RPC ACEPTA la
   transacción, y desde ahí todavía puede caducar sin llegar a la cadena. Marcar la entrega sin
   mirar el efecto es lo que dejó un Charizard de 93 $ dentro de un escrow con `transferred=1`, y
   ese flag falso además cegaba al barrido, que busca justo por lo contrario.
"""
from __future__ import annotations

import logging
from typing import Awaitable, Callable, Optional

from sqlalchemy.orm import Session

from ..models import CrackoutSlab
from .nft_transfer import UnsupportedNftStandard, build_transfer, nft_in_owner, submit_signed_tx
from .pack_orchestration import fetch_latest_blockhash

logger = logging.getLogger(__name__)

Confirmador = Callable[[str, str, str], Awaitable[bool]]


async def entregar(session: Session, losa: CrackoutSlab, *, rpc_url: str, signer,
                   vitrina_wallet_id: str, vitrina_address: str,
                   operator_wallet_id: str, operator_address: str,
                   confirmar_llegada: Optional[Confirmador] = None) -> Optional[str]:
    """Mueve la carta de la vitrina al ganador. Devuelve la firma, "ya-estaba", o None si no se
    pudo. Idempotente: se puede reintentar sin miedo.

    None NO es una carta perdida: la losa se queda `broken` con `delivery_signature` nula, que es
    un estado visible que `scripts/crackout.py --entregar` vuelve a intentar.
    """
    if losa.status != "broken" or not losa.broken_by:
        return None
    if losa.delivery_signature:
        return losa.delivery_signature

    confirmar = confirmar_llegada or nft_in_owner
    ganador, mint = losa.broken_by, losa.nft_address

    try:
        if await nft_in_owner(rpc_url, ganador, mint):
            # Llegó en su día y no se registró: basta con anotarlo, sin mover nada ni gastar gas.
            losa.delivery_signature = "ya-estaba"
            session.commit()
            return "ya-estaba"

        bh = await fetch_latest_blockhash(rpc_url)
        tx = await build_transfer(rpc_url, vitrina_address, ganador, mint, bh,
                                  fee_payer=operator_address)
        firmada = await signer.sign_solana(vitrina_wallet_id, tx)       # dueña de la carta
        firmada = await signer.sign_solana(operator_wallet_id, firmada)  # paga gas y alquiler
        firma = await submit_signed_tx(rpc_url, firmada)

        if not await confirmar(rpc_url, ganador, mint):
            logger.warning("crackout %s: enviada pero la carta no ha llegado a %s",
                           losa.id, ganador)
            return None

        losa.delivery_signature = firma
        session.commit()
        return firma
    except UnsupportedNftStandard as exc:
        logger.error("crackout %s: estándar de carta no soportado: %s", losa.id, exc)
        return None
    except Exception as exc:                     # noqa: BLE001
        logger.error("crackout %s: falló la entrega: %s", losa.id, exc)
        return None
```

```python
"""Poner una losa de Crackout, y reintentar las entregas que quedaron a medias.

POR QUÉ ES UN SCRIPT Y NO UN ENDPOINT. El backend no tiene hoy ni un solo endpoint de
administración. Abrir el primero justo para esto sería añadir una puerta que luego hay que
vigilar; un script se ejecuta desde la máquina y no expone nada.

Antes de crear una losa, la carta tiene que estar YA en la vitrina (CRACKOUT_WALLET_ADDRESS).
El script lo comprueba on-chain: si no está, no compromete nada.

    python scripts/crackout.py listar
    python scripts/crackout.py crear --mint <mint> --coste 10            # dry-run
    python scripts/crackout.py crear --mint <mint> --coste 10 --go
    python scripts/crackout.py entregar --go

Con APP_NETWORK=mainnet trabaja contra mainnet (misma superposición de .env que el backend).
"""
from __future__ import annotations

import argparse
import asyncio
import secrets as _secrets
import sys

from app.config import get_settings
from app.db import make_engine, make_session_factory
from app.models import CrackoutSlab
from app.services.crackout_chain import (N_POR_DEFECTO, denominador, derivar_semilla,
                                         extremo_cadena)
from app.services.crackout_delivery import entregar
from app.services.nft_transfer import nft_in_owner
from app.services.privy_signer import PrivySigner
from scripts._destino import anunciar

#: D por encima de esto no deja 10x de margen sobre la cadena. Son unos 500 $ de valor asegurado.
D_MAXIMO = N_POR_DEFECTO // 10


class MargenInsuficiente(Exception):
    """La carta es tan cara que su D no deja margen de cadena suficiente."""


def _log(m: str = "") -> None:
    print(m, flush=True)


def preparar_losa(*, slab_id: str, nft_address: str, name: str | None, image_url: str | None,
                  insured_value: float, cost_points: int, secret: str,
                  n: int = N_POR_DEFECTO) -> CrackoutSlab:
    """Construye la fila con su compromiso ya calculado. NO toca la base ni la cadena de Solana.

    Todo lo que sale de aquí es inmutable a partir de que se guarde: chain_head, chain_length,
    denominator y cost_points. Corregir cualquiera de ellos después invalida en silencio todas las
    verificaciones pasadas, así que una losa mal creada se abandona y se crea otra.
    """
    if not secret:
        raise ValueError("hace falta CRACKOUT_SECRET para comprometer una cadena")
    if cost_points <= 0:
        raise ValueError("el coste del golpe tiene que ser positivo")
    d = denominador(insured_value)
    if d > D_MAXIMO:
        raise MargenInsuficiente(
            f"D={d} supera {D_MAXIMO}: la cadena de {n} eslabones no deja 10x de margen. "
            "Una losa que agota la cadena obliga a recomprometer en público."
        )
    head = extremo_cadena(derivar_semilla(secret, slab_id), n)
    return CrackoutSlab(id=slab_id, nft_address=nft_address, name=name, image_url=image_url,
                        insured_value=insured_value, chain_head=head, chain_length=n,
                        denominator=d, cost_points=cost_points)


async def _crear(args, st, s) -> None:
    if not st.crackout_wallet_address:
        _log("CRACKOUT_WALLET_ADDRESS está vacío: no hay vitrina donde mirar.")
        return
    _log(f"Comprobando que {args.mint} está en la vitrina {st.crackout_wallet_address}…")
    if not await nft_in_owner(st.solana_rpc_url, st.crackout_wallet_address, args.mint):
        _log("La carta NO está en la vitrina. No se compromete nada.")
        return

    slab_id = args.id or _secrets.token_hex(4)
    losa = preparar_losa(slab_id=slab_id, nft_address=args.mint, name=args.nombre,
                         image_url=args.imagen, insured_value=args.valor,
                         cost_points=args.coste, secret=st.crackout_secret)
    _log("")
    _log(f"  losa        {losa.id}")
```

```typescript
/**
 * El verificador de Crackout. Rehace la cadena de hashes ENTERA en el navegador.
 *
 * El punto del modo es este fichero: la comprobación no la hace el backend, la hace quien mira.
 * Se descarga el registro público de golpes y se recorre hacia atras hasta el extremo que se
 * publico al crear la losa. Si algo no encaja, se dice cual es el golpe exacto.
 *
 * Reimplementa a proposito lo que hace `backend/app/services/crackout_chain.py`. Que los dos lados
 * no puedan separarse en silencio lo garantiza `shared/crackout-vector.json`, que leen las pruebas
 * de aqui y las de alli. Si divergieran, esta pagina acusaria de tramposos a golpes correctos, y
 * eso destruye la confianza mas rapido que no tener pagina.
 *
 * Lo que esto demuestra: que no cambiamos el resultado de un golpe.
 * Lo que NO demuestra: que no podamos influir en a quien le toca cada eslabon.
 */

export type Hit = {
  hit_index: number
  wallet: string
  client_seed: string
  link: string
  roll: string // 64 bits: viaja como texto porque JSON.parse lo redondearia
  broke: boolean
  cost_points: number
  ts: string | null
}

export type VerifyResult = {
  ok: boolean
  checked: number
  failedAt: number | null
  reason: string | null
}

const hex = (buf: ArrayBuffer): string =>
  Array.from(new Uint8Array(buf))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('')

/** sha256 de la cadena HEXADECIMAL en UTF-8, no de los bytes decodificados. Igual que Python. */
export async function sha256Hex(text: string): Promise<string> {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(text))
  return hex(buf)
}

/**
 * D, tal que p = 1/D. `Math.floor(x + 0.5)` en vez de `Math.round` para que el codigo diga en voz
 * alta cual es la regla: Python redondea a par con round(), y aqui hace falta la otra.
 */
export function denominatorFor(insuredValue: number): number {
  return Math.max(2, Math.floor(insuredValue * 2 + 0.5))
}

/** El dado: HMAC-SHA256 con el eslabon como clave (su texto hex en UTF-8) y los 8 primeros bytes. */
export async function rollFor(link: string, clientSeed: string): Promise<bigint> {
  const key = await crypto.subtle.importKey(
    'raw',
    new TextEncoder().encode(link),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign'],
  )
  const sig = await crypto.subtle.sign('HMAC', key, new TextEncoder().encode(clientSeed))
  const bytes = new Uint8Array(sig).slice(0, 8)
  let n = 0n
  for (const b of bytes) n = (n << 8n) | BigInt(b)
  return n
}

/**
 * Recorre el registro. `chainHead` es el extremo publicado y hace de "eslabon anterior" del
 * primero. Devuelve el indice del primer golpe que no cuadra, si alguno no cuadra.
 */
export async function verifyChain(
  chainHead: string,
  hits: Hit[],
  denominator: number,
): Promise<VerifyResult> {
  let previous = chainHead
  let checked = 0
  const fail = (h: Hit, reason: string): VerifyResult => ({
    ok: false,
    checked,
    failedAt: h.hit_index,
    reason,
  })

  for (let i = 0; i < hits.length; i++) {
    const h = hits[i]
    // Los golpes tienen que ser consecutivos: un hueco significa que falta un eslabon del medio,
    // y sin el no se puede encadenar con el siguiente. Es el sintoma de un reordenamiento.
    if (i > 0 && h.hit_index !== hits[i - 1].hit_index + 1) {
      return fail(h, `falta el golpe ${hits[i - 1].hit_index + 1}`)
    }
    if ((await sha256Hex(h.link)) !== previous) {
      return fail(h, 'el eslabon no encadena con el anterior')
    }
    const roll = await rollFor(h.link, h.client_seed)
    if (roll.toString() !== h.roll) {
      return fail(h, 'el dado no sale de este eslabon')
    }
    if (roll % BigInt(denominator) === 0n !== h.broke) {
      return fail(h, 'el resultado no cuadra con el dado')
    }
    previous = h.link
    checked++
  }
  return { ok: true, checked, failedAt: null, reason: null }
}
```

```typescript
  return (await res.json()) as T
}

  fetch(`${config.backendUrl}/crackout/${encodeURIComponent(id)}/hits?after=${after}`, {

  }).then(json)

 * el eslabon, asi que no hay ningun momento en el que se vea el resultado sin haberlo pagado. */
export async function strikeSlab(
  id: string,
  clientSeed: string,
  identityToken: string,
): Promise<StrikeResult> {
  const res = await fetch(`${config.backendUrl}/crackout/${encodeURIComponent(id)}/hit`, {
    method: 'POST',
    headers: {
      ...headers,
      'Content-Type': 'application/json',
      Authorization: `Bearer ${identityToken}`,
    },
    body: JSON.stringify({ client_seed: clientSeed }),
  })
  if (res.status === 402) throw new Error('sin_puntos')
  if (res.status === 409) throw new Error('losa_cerrada')
  return json<StrikeResult>(res)
}
```

```tsx
      const r = await strikeSlab(id, newClientSeed(), identityToken)
      setGolpes((prev) => [r.hit, ...prev])
      setLosa(r.slab)
      setPuntos(r.points_left)
    } catch (e) {
      setError(ERRORES[(e as Error).message] ?? 'No se ha podido dar el golpe')
    } finally {
      setGolpeando(false)
    }
  }, [id, identityToken, golpeando])

  if (!losa) return <div style={{ padding: 24, color: COLORS.muted }}>Cargando la losa…</div>

  const viva = losa.status === 'live'

  return (
    <div style={{ padding: 24, maxWidth: 860, margin: '0 auto', color: COLORS.text }}>
      <h1 style={{ fontFamily: FONTS.display, fontSize: 28, margin: 0 }}>
        {losa.name ?? 'Carta sin nombre'}
      </h1>

      <div style={{ display: 'flex', gap: 24, flexWrap: 'wrap', margin: '16px 0' }}>
        <Dato etiqueta="Probabilidad" valor={`1 entre ${losa.denominator}`} />
        <Dato etiqueta="Golpe" valor={`${losa.cost_points} gimmighouls`} />
        <Dato etiqueta="Golpes dados" valor={String(losa.hits)} />
        {puntos !== null && <Dato etiqueta="Te quedan" valor={`${puntos} puntos`} />}
      </div>

      {viva ? (
        <button
          type="button"
          onClick={golpear}
          disabled={golpeando || !identityToken}
          style={{
            fontFamily: FONTS.display, fontSize: 18, padding: '12px 28px', borderRadius: 12,
            cursor: golpeando ? 'wait' : 'pointer', color: COLORS.bg, background: COLORS.green,
            border: 'none', opacity: identityToken ? 1 : 0.5,
          }}
        >
          {golpeando ? 'Golpeando…' : 'Golpear'}
        </button>
      ) : (
        <p style={{ color: COLORS.muted }}>
          Losa rota{losa.broken_by ? ` por ${corta(losa.broken_by)}` : ''}. Ya no admite golpes.
        </p>
      )}

      {error && <p style={{ color: COLORS.red }}>{error}</p>}

      <p style={{ color: COLORS.muted, fontSize: 13, marginTop: 20, maxWidth: 620 }}>
        Cada golpe revela su eslabon en el momento, ganes o pierdas, y encadena con el anterior.
        Eso demuestra que no podemos cambiar el resultado de un golpe. No demuestra que no podamos
        influir en el orden en que se reparten, y por eso no lo prometemos.{' '}
        <Link to={`/play/crackout/${id}/verify`} style={{ color: COLORS.green }}>
          Comprobarlo tu mismo
        </Link>
      </p>

      <h2 style={{ fontFamily: FONTS.display, fontSize: 18, marginTop: 28 }}>Golpes</h2>
      {golpes.length === 0 && <p style={{ color: COLORS.muted }}>Todavia no ha golpeado nadie.</p>}
      {golpes.map((h) => (
        <div
          key={h.hit_index}
          style={{
            fontFamily: FONTS.mono, fontSize: 12, padding: '8px 12px', marginBottom: 6,
            borderRadius: 8, background: COLORS.panel,
            border: `1px solid ${h.broke ? COLORS.green : COLORS.border}`,
          }}
        >
          <span style={{ color: COLORS.muted }}>#{h.hit_index}</span>{' '}
          <span>{corta(h.wallet)}</span>{' '}
          <span style={{ color: COLORS.muted }}>{h.link.slice(0, 16)}…</span>{' '}
          <span style={{ color: h.broke ? COLORS.green : COLORS.muted }}>
            {h.broke ? 'ROMPE' : 'aguanta'}
          </span>
        </div>
      ))}
    </div>
  )
}

function Dato({ etiqueta, valor }: { etiqueta: string; valor: string }) {
  return (
    <div>
      <div style={{ fontFamily: FONTS.mono, fontSize: 10, letterSpacing: '.1em', color: COLORS.muted }}>
        {etiqueta.toUpperCase()}
      </div>
      <div style={{ fontFamily: FONTS.display, fontSize: 22 }}>{valor}</div>
    </div>
  )
}
```
